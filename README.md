# SDNTask – FastAPI сервис для работы с городами и геоданными

## О проекте

Проект представляет собой асинхронное веб-приложение на **FastAPI**, которое позволяет:

- Получать информацию о городе из базы данных (название, широта, долгота).
- Находить два ближайших города к заданным координатам (по формуле гаверсинуса).
- Добавлять новый город: данные о координатах автоматически запрашиваются у внешнего API **Nominatim** (OpenStreetMap) и сохраняются в PostgreSQL.
- Удалять город из базы по названию.

Приложение использует **SQLAlchemy 2.0** (асинхронный режим) для работы с PostgreSQL, **aiohttp** для вызовов внешнего API, а также **Pydantic** для валидации схем.

## Внешнее API

Для получения координат по названию города используется **Nominatim** (OpenStreetMap).  
Базовый URL: `https://nominatim.openstreetmap.org/search`
